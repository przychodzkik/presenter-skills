# presenter-skills

Small skills that help you turn an idea and raw materials into a better speech or presentation. They cover the whole path: who the audience is, the hook, the story, the structure, the script, and only then the slides. If you want a wall-of-text slidedoc, there is a skill for that too.

Each skill does one job, works on its own, and hands work to the next one through plain files in a `presentation/` folder.

## Install

Add the marketplace, then install the plugin:

```
/plugin marketplace add <github-owner>/presenter-skills
/plugin install presenter-skills@presenter-skills
```

## Skills

| Skill | Job | Status |
|---|---|---|
| `presenting-vocabulary` | Shared terms and cited frameworks the other skills use | available |
| `presenter-start` | Tells you which skill to use next | planned |
| `presentation-brief` | Interviews you about the occasion, audience and goal | available |
| `storytelling` | Hooks and stories from your real material | available |
| `structuring` | Outline: opener, body blocks, one call to action | available |
| `scripting` | The full speakable script | planned |
| `slide-plan` | Written plan for live slides | planned |
| `slidedoc` | A slide document written to be read | planned |

The skills reply in the language you write in.

## Sources

The skills are built on public frameworks, and each claim is tagged *research-backed* or *craft heuristic*:

- Chip Heath and Dan Heath, *Made to Stick*
- Nancy Duarte, *Resonate* and the slidedoc format
- Daniel Kahneman, *Thinking, Fast and Slow*
- Robert McKee, *Story*
- George Loewenstein, information-gap theory of curiosity
- Lehne and Koelsch, a model of tension and suspense
- Barbara Minto, *The Pyramid Principle*
- S. I. Hayakawa, *Language in Thought and Action* (ladder of abstraction)
- Cole Nussbaumer Knaflic, *Storytelling with Data*
- Gestalt psychology and the picture superiority effect

These skills were developed from the author's own training and practice. No third-party course text, slides or examples are reproduced.
