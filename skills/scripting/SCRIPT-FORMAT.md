# presentation/script.md

Terms follow `presenting-vocabulary`.

```md
# Script: <working title>

- Core message:
- Target length: <words> and <minutes>

## Opener

[c1] First paragraph, written to be spoken aloud.

[c2] Next paragraph.

## <Block title from the outline>

[c3] ...

## Close

[c9] ...
```

## Cue ids

Every paragraph starts with a cue id such as `[c3]`, numbered in order and never reused. `slide-plan` anchors each slide to a cue id, so keep ids stable when editing: add new paragraphs with the next free number and leave old ids in place.

## Markers

- `[pause]` for a deliberate silence.
- `**word**` for a word to stress.
- `[needs example]` where a concrete example, number or image is still missing, followed by what is needed.
- Text taken from `hook.md` or `story.md` is marked with `[from hook]` or `[from story]` at the start of the paragraph so it stays unchanged on later edits.
